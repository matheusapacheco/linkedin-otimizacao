# Modelos dos arquivos que a entrevista grava

Todos ficam na raiz da pasta de trabalho da pessoa. Campos não respondidos ficam como `[LACUNA]`. Nunca preencher com suposição.

---

## banco-de-casos.md

Um bloco por resultado. O campo "última vez usado" começa vazio e evita repetir o mesmo caso em sequência.

```markdown
## [nome curto do caso]
- Contexto:
- Problema:
- O que eu decidi ou fiz:
- Resultado com número:
- Restrição de uso: pode citar tudo | não nomear o cliente | só o resultado
- Onde já foi usado:
- Última vez usado:
```

## diagnostico.md

```markdown
# Diagnóstico
Data: DD/MM/AAAA

## Nível de preparo
Pronta para aplicar agora | Precisa de ajustes de 2 a 4 semanas | Precisa de preparação maior
Justificativa em 2 linhas.

## Pontos fortes
- até 3 itens

## Gaps críticos (no máximo 3)
1. gap, evidência, impacto em entrevista
2.
3.

## Estratégia recomendada
Remoto | Relocação | Híbrido | Recolocação local, e a justificativa em 1 frase.

## Primeira ação
Skill a rodar agora e por quê.
```

## plano-90-dias.md

```markdown
# Plano de 90 dias
Início: DD/MM/AAAA | Tempo por semana: X horas

## Dias 1 a 30: base que gera entrevista
Gap crítico a corrigir primeiro:
- [ ] tarefa, quem faz, skill que ajuda, prazo
Métricas ao fim da fase:

## Dias 31 a 60: posicionamento e rede
- [ ] tarefa
Métricas ao fim da fase:

## Dias 61 a 90: candidaturas e entrevistas
- [ ] tarefa
Métricas ao fim da fase:

## Métricas acompanhadas (revisão mensal)
| Métrica | Linha de base | Dia 30 | Dia 60 | Dia 90 |
|---|---|---|---|---|
| Visualizações do perfil (90 dias) | | | | |
| Ocorrências em pesquisa (7 dias) | | | | |
| Cargo-alvo aparece nos cargos buscados | | | | |
| Conexões qualificadas novas | | | | |
| Candidaturas estratégicas | | | | |
| Respostas recebidas | | | | |
| Convites para entrevista | | | | |

## Registro de recusas e ajustes de rota
Data, o que aconteceu, o que isso informa, ajuste feito.
```

Regras do plano:
- Tarefas cabem no tempo semanal informado. Até 2 horas por semana: só perfil e candidatura. De 3 a 5: inclui rede. Mais de 5: inclui conteúdo.
- No máximo 3 tarefas principais por semana.
- Modo caça só aparece no plano se a pessoa tiver ligado explicitamente, com o teto de convites que ela escolheu.
